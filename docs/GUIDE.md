# 安装与迁移

[返回首页](../README.md)

## 第一次使用

当前提供 Windows x64 0.7.0 预览版。进入 [Windows installer](https://github.com/z0332767-hash/reading-archive/actions/workflows/windows.yml)，打开成功构建，在 Artifacts 下载 `Reading-Archive-Windows-x64`。

解压 ZIP 后运行其中的 `.exe`，按向导安装，再通过桌面图标启动。无需安装 Node.js。仓库当前为私有，下载需要访问权限；构建产物保留 30 天。

这是未签名的测试版本。如果遇到系统提示，请先确认文件来源，不要关闭系统安全防护。安装成功不代表所有交互已在你的电脑上验证。

先用内置示例熟悉“书库 → 书籍详情 → 待整理 → 今天”。应用示例不是你的真实账号数据。

## 从双击脚本的旧版迁移

1. 用原浏览器和原地址打开旧版，点击“导出 JSON”，保留备份。
2. 在桌面版“导入”中选择该文件。
3. 检查书籍和笔记预览，再确认写入；导入采用合并规则，内置示例可能仍会保留。
4. 抽查书籍、点评、观点和回顾，再重新配置需要的连接。

JSON 备份包含观点、问题、回顾和读完结案页，不包含 API Key。Markdown 适合阅读和写作，迁移请使用 JSON。确认完整前保留旧版与原备份。

“恢复示例数据”会覆盖当前档案，不是清空示例的按钮，请勿用它清理已导入的数据。

## 连接微信读书

在应用“微信读书”页面打开授权入口，按微信读书页面的流程获取 Key，再回到应用验证保存。首次建议选择最近 20 本，读取并检查预览后写入。

入口：[微信读书技能页面](https://weread.qq.com/r/weread-skills)。入口、可用范围和授权方式以该页面实际说明为准。

同步由你手动触发，只导入接口提供的数据，不导出电子书全文。划线与对应想法会尽量合并展示；统计口径可能与微信读书页面不同。

## 备份与更新

- 大量导入或安装新版前导出 JSON，存到你自己选择的位置。
- 菜单“阅读档案 → 打开数据目录”可以定位本地数据。
- 数据目录与安装目录分离，请勿手动删除 `%APPDATA%/ReadingArchive`。
- 首版没有自动更新。下载新版安装包后退出旧应用，再安装更新。
- 端口 4174 被占用时应用会提示启动失败。关闭占用程序后重试，应用不会自动换地址。

## 常见问题

**安装后看不到旧笔记？** 桌面版与浏览器版使用不同存储，需要导出后导入。旧版也请使用原浏览器、原端口和原地址。

**一定要配置 AI 吗？** 不需要。本地检索和摘要可单独使用；AI 综合回答才会调用外部服务，并可能产生服务费用。

**朋友打不开下载链接？** 当前仓库为私有，公开发布或邀请访问需由项目拥有者决定。
