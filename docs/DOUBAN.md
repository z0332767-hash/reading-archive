# 豆瓣连接验证（0.7.1 实验版）

本版本验证本机豆瓣访问与分页，不是完整影视导入功能。不修改阅读档案，不自动获取全部记录，也未实现长影评导入。

1. 安装 0.7.1 后，从桌面应用顶部菜单「阅读档案 → 豆瓣连接验证（实验）」进入。
2. 在本机豆瓣窗口自行登录，打开自己的「看过」列表。也可以使用窗口顶部「豆瓣验证 → 1. 打开我的看过列表」。
3. 点击「豆瓣验证 → 2. 验证当前页与下一页」。最多读取两页，显示记录数和包含短评的数量。
4. 将成功数量或错误提示反馈即可，无需发送密码、Cookie 或逐页保存网页。

可以选择保存 JSON 验证样本到本机；该格式暂不支持现有阅读档案导入。样本包含作品名称、评分、日期和短评，不包含登录凭据。请勿提交个人样本到公开仓库。

登录窗口使用独立的内存会话，关闭后结束会话。远程网页没有 Node.js 或本地档案接口权限。遇到登录验证、页面变化或加载失败会停止；不会规避验证码或访问限制。如果代理线路无法访问豆瓣，可在本机切换到可用网络后重新打开窗口。

代码与既有回归测试可在开发环境验证；真实登录、网络访问、Windows 交互仍需实机验证。成功读取两页不代表全量同步已经实现。
